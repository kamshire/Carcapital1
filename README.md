# CarCapital

Premium vehicle rental + private security landing page.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system
- `script.js` — reveal animations and subtle hero interaction

## Run
Open `index.html` directly in a browser, or deploy the repository with a static host such as Vercel/GitHub Pages.

## Before launch
Replace the placeholder phone/email, pricing, vehicle imagery, and service claims with the company's real details. The current images are loaded from Unsplash URLs.
